# TableGo bundled fonts

Inter, Cormorant Garamond and Playfair Display are distributed under the included SIL Open Font Licenses. These WOFF2 files were copied byte-for-byte from the tested TableGo deployment to preserve its font subsets, styles, weights, fallback metrics and preload behavior while removing Google font downloads from builds.

Upstream sources: https://github.com/google/fonts/tree/main/ofl/inter, https://github.com/google/fonts/tree/main/ofl/cormorantgaramond, https://github.com/google/fonts/tree/main/ofl/playfairdisplay.
